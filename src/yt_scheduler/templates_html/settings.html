Media hosting (Cloudflare R2)

Threads doesn't accept a media upload — images and video alike, its API fetches them from a URL Meta cURLs itself, and this app serves on 127.0.0.1. Attachments are put in a private R2 bucket and handed to Meta as a signed URL that expires, so the bucket is never publicly readable. Keys are stored in Keychain; the bucket and account ID are not secret and live in the database.
